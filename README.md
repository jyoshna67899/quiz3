# QuizMaster CRT — New GitHub Pages Version

A GitHub Pages-only degree placement/CRT quiz platform.

## Main behavior

**All Subjects** = mixed questions from every available subject.

**All Levels** = Easy + Medium + Hard.

**All Companies** = mixed company-style practice across 58 company labels.

You can therefore select **All Subjects + All Levels + All Companies** for a complete mixed CRT mock test.

## Question bank
The browser loads a large local question bank with **1,200 questions per subject** (15,600 total generated practice questions).

The company labels mean **practice style/category only**. They are not official company exam questions or leaked material.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, `questions.js`.
3. Open **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

No backend, database, API key, or server is required.
